PixieVeil v–

A DICOM anonymization server. It receives images over DICOM C-STORE, anonymizes them profile-by-profile following DICOM PS3.15, optionally removes facial features from head scans with a deep-learning model, extracts RHYTHM dose-registry exam data, and holds every study for a person to review before it is sent anywhere.

Standards & formats

DICOM PS3.15 Annex E — the attribute confidentiality profiles that the anonymization profiles (research, gdpr) are modelled on.

Accepted storage SOP classes — anything else is refused at association time:

RHYTHM CT protocol registry — the exam-entry fields extracted and reviewed on the Studies page follow its manual exam-entry and protocol forms. Dose values come from the TID 10011 X-Ray Radiation Dose Report when the scanner sends one.

Defacing pipeline — CT-DEFACE and CTA-DEFACE

Based on CT-DEFACE by jsfakian, which is derived from CTA-DEFACE by CCI Bonn. If you publish work that used defacing, please cite:

nnU-Net

The self-configuring segmentation framework the defacing model runs on (MIC-DKFZ/nnUNet).

Anonymization profiles — dicom_anonymization

Inspired by dicom_anonymization by jsfakian (MIT License), which introduced the JSON-profile approach, deterministic salt-based pseudonymisation and the GDPR-strict profile concept adopted here.
